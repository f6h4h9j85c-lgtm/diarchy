# diarchy

diarchy runs two AI coding agents, Claude Code and OpenAI Codex CLI, each as a
product manager with its own team of subagents. The two PMs coordinate
PM-to-PM through markdown files in an Obsidian vault, speaking a message
protocol that is enforced in code, so the conversation cannot drift into
agent-to-agent noise.

Status: pre-alpha, under construction.
