## Decisions
- Enforcement lives in the MCP server and store, not in prompts (prompts drift; validators do not).
- Lead = agent that received the kickoff; challenger = the other; roles swap per goal; no routing by model or frontend/backend; disagreements settled by the cheapest test, lead authority only when no test exists.
- One file per message, never edited; the store renders the human views. Avoids merge conflicts and the two-monologue problem.
- Worktree per PM, PRs, cross-model review required for DONE.
- Human paged only on deadlock, external blocker, or spent budget; ASK_HUMAN is system-only.
- Node engines >=20 kept for v1 (forces commander 14, vitest 4). Install from GitHub via `prepare` build; not on npm.
- Deadlock hint omits `--decision plan` while another thread is open (PHASE_GATE would reject it).
