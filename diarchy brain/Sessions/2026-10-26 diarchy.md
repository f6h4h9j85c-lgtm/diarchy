## Decisions
- Codex sandbox stays on by default; `diarchy init --codex-full-access` opts out with a warning (CEO, 2026-10-25). A sandboxed Codex PM cannot commit, so the other PM commits for it, cites only `commit`, and Codex posts its own `pr` evidence (keeps authorship and cross-review right).
- Agent text in chat.md, goal.md and decisions.md is plain text: every ASCII punctuation character escaped, default-ignorables stripped (third attempt; two escaping approaches were forgeable).
- Guard design: the original split verdict is the floor; only inert quoted text handed to data-only programs is exempt (third attempt; two quote-aware parsers each lost real denies).
- Explicit slug reuse of a DONE goal id is refused; a derived slug gets the next free suffix.
- Stored chat files written by 0.1.0 are read with 0.1.0's field rules; new posts get the tightened rules. No protocol_version bump.
- Node >= 20.3 (AbortSignal.any).
- Audit process: verification votes from any workflow count; a round-2 finding survives only with zero refutes; fixes base on the latest approved branch; fixers must not use git stash in a shared repo.
